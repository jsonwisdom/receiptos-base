# Cross-Language Interoperability Contract

This directory defines the **parity vector** that every ReplayOS
implementation (Python, Go, Rust, …) must match.

## Normative fixture corpus

```
tests/fixtures/
├── valid/
│   └── basic_release/          # known-good release tree + manifest
└── corrupted/
    └── digest_mismatch/        # same tree, fixture digest deliberately wrong
```

Each case directory is self-contained: it contains a `manifest.json`
and all artifacts referenced by relative `file://` URIs.

## Parity vector

Generated by the reference implementation:

```bash
cd tools/manifest_verify
PYTHONPATH=. python3 replayos_cli.py interop \
  --fixtures-dir ../../tests/fixtures \
  --output ../../tests/interop/parity_vector.json
```

The vector is **canonical JSON** (`sort_keys=True`, stable key order).
Implementations MUST produce an identical byte stream for the fields:

| Field | Meaning |
|-------|---------|
| `cases[].valid` | Overall verification outcome |
| `cases[].integrity_ok` | Root-digest match |
| `cases[].artifacts_ok` | All artifact digests match |
| `cases[].root_digest` | The `integrity.root_digest` value from the manifest |
| `cases[].artifact_statuses[]` | Ordered list of `{uri, status}` where status ∈ {PASS, FAIL, NO_DIGEST, NOT_VERIFIED} |
| `cases[].error_count` | Number of error messages (not the text) |

## Gatekeeper invariant

No implementation may emit an `AttestationEnvelope` (or any witness)
when `valid == false`.  The Python reference enforces this in
`gatekeeper.enforce_attestation_gate`.

## Adding a language

1. Implement a verifier that consumes the same fixture directories.
2. Emit a parity vector with the schema above.
3. CI compares your vector to `tests/interop/parity_vector.json`
   with a byte-equality check (or a structured field-equality check
   if timestamps / non-normative fields differ).

See Issue #154 for the full freeze acceptance criteria.
